# Portfolio - Chu Thi Hien

Trang portfolio CV tĩnh được xây dựng bằng HTML5 và CSS3, có hiệu ứng Animate.css.

## Chạy trên máy

Mở `index.html` bằng trình duyệt hoặc chạy bằng tiện ích Live Server trong VS Code.

## Đưa lên GitHub Pages

1. Tải các tệp trong dự án lên repository GitHub.
2. Mở **Settings → Pages** của repository.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn nhánh `main` và thư mục `/(root)`, sau đó nhấn **Save**.
5. Chờ GitHub Pages triển khai và mở đường dẫn được hiển thị trong mục Pages.

Giữ nguyên cấu trúc thư mục `assets` để CSS và hình ảnh được tải đúng. Animate.css được tải từ CDN nên cần kết nối Internet để hiệu ứng hoạt động.

## Trước khi xuất bản

Cập nhật email, liên kết GitHub/LinkedIn và các liên kết dự án trong `index.html` thành thông tin thật của bạn.
